# Device identification and support

The curated catalog contains 7 real devices / 11 explicitly identified variants. See [the catalog ledger](docs/catalog/README.md) for each model, primary source, reviewed date, excluded variants and source availability limits.

Identification (`CATALOGED`), maintained source availability (`SOURCE_AVAILABLE`) and ROMCRAFT build verification are separate facts. All current devices and Android bases have `NOT_VERIFIED` build status and `UNKNOWN` compatibility. No verified device-specific build manifests or workers exist. Source metadata never implies device/base compatibility.

The older fictional devices remain stored as deprecated, unverified records so saved projects continue to resolve their original selections. They are excluded from new-device selection. No user project is mapped onto real hardware automatically.
