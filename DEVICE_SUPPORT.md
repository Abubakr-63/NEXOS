# Device support

No device is currently build-ready. Seeded catalog entries are fictional. An existing variant ID confirms identity in the catalog, not Android build support.

The foundation validator returns UNKNOWN with blocking issues for missing manifests, device trees, vendor dependencies, firmware, base, kernel and recovery evidence. Unrecognized variants add a blocking issue. No arbitrary Android base or kernel can be selected through the strict configuration schema.

Application roles and named preset intentions are saved preferences only; they do not contain verified APKs or device capabilities. Theme rendering is an approximation.
