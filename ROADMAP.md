# Phased roadmap

1. Foundation and first visual slice: implemented with explicit save, revision history API, preview and fail-closed validation.
2. Finish foundation: email delivery, reset/verification tokens, quotas, structured telemetry, localization, detailed OpenAPI schemas and reusable form/state tooling.
3. Complete builder: evidenced variant catalog, schema-driven capability controls, real preset configurations, autosave/conflict recovery, redo and revision restoration.
4. Build infrastructure: one reviewed device manifest, hardened Linux worker, queue lifecycle, SSE, cancellation, signed artifacts and tests.
5. Device-specific installation guidance and evidence-separated boot/hardware validation.

No forums, reputation systems, social network or generic download directory are planned.
